# Kinect Filter

![Screenshot](https://github.com/Camuise/kinect-filter/blob/main/screenshot.png?raw=true)

Tried to recreate the depth map preview the Xbox 360 Kinect used to show when you were in front of the camera. The depth map is generated using the MiDaS model.

Doesn't work very well since it's pretty dificult to detect depth using a single webcam, so this doesn't particularly work.

Also has a bunch of random customizations that make it only work on Apple Silicon Macs, so yeah.

This is a stupid project that I made for fun, don't use it.
